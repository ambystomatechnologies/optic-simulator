# Simulador de Óptica 2D - Ambystoma Studio
**Interactive 2D Ray Tracing & Optics Simulator for the Web**

Desarrollado por **Ambystoma Technologies** · 100% Gratuito y de Código Abierto.

---

## 🔬 Características Principales

- **Trazado de Rayos 2D en Tiempo Real (60 FPS):** Implementación vectorizada de la Ley de Snell, Reflexión Especular y Reflexión Total Interna (TIR).
- **Dispersión Cromática (Ecuación de Cauchy):** Separación real de las longitudes de onda del arcoíris al atravesar prismas y medios dispersivos.
- **Lentes Personalizadas y Deformación de Nodos:** Modo de esculpido de vértices para inventar cualquier lente con curvas suaves Catmull-Rom.
- **Dibujo a Mano Alzada y Polígonos:** Dibuja tus propias ópticas directamente sobre el lienzo.
- **Fuentes de Luz Múltiples:** Láser monocromático, fuentes puntuales en abanico, haces paralelos y objetos emisores (tipo lápiz).
- **Botón Dedicado "Agregar nueva fuente de luz":** Añade fuentes configurables en cualquier momento.
- **Detector / Pantalla de Luz:** Registra impactos fotónicos y muestra histogramas de distribución espectral.
- **Regla / Medidor Óptico:** Mide distancias en milímetros y ángulos relativos.
- **Bilingüe (Inglés por defecto / Español):** Selector con banderas circulares en el encabezado.
- **Diseño Cyber-Dark Theme:** Modo oscuro con brillo óptico realista, adaptable a pantallas de alta resolución.
- **Listo para GitHub Pages:** Ejecutable en cualquier navegador sin servidores ni dependencias.

## 🚀 Cómo Ejecutar en Local

1. Haz doble clic en `start.bat` o ejecuta en terminal:
   ```bash
   python -m http.server 8081
   ```
2. Abre en tu navegador web: `http://localhost:8081/index.html`

O abre directamente el archivo `index.html` en cualquier explorador de internet.
