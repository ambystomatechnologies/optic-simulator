About 2D Optics Simulator

Development & Scientific Software

Interactive high-performance web optics suite developed by Ambystoma Technologies.

🔬 Physics Engine Highlights
  • Vector Snell's Law with Total Internal Reflection (TIR) calculation.
  • Cauchy's dispersion equation enabling true chromatic rainbow splitting.
  • Catmull-Rom closed splines for sculptable organic lenses and node deformation.
  • Detector screens with real-time photon intensity distribution graphs.
✨ 100% Free & Open-Access

This tool is completely free, runs locally in your web browser with hardware-accelerated Canvas, requires no signup, and does not send any data to external servers.
